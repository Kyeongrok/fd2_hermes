# ANI.DAT AFM 포맷 분석 문서

## 개요

ANI.DAT는 FD2 게임의 애니메이션 데이터 파일로, 여러 개의 AFM (Animation File Manager) 리소스를 포함합니다. 각 AFM 리소스는 독립적인 애니메이션 클립입니다.

## 파일 구조

### 파일 헤더
- 매직 넘버: 6바이트 "LLLLLL"
- 인덱스 테이블: 오프셋 6부터 시작, 항목당 4바이트 (32비트 오프셋)

### AFM 리소스 인덱스
```
오프셋 6:  AFM 0 오프셋 (4바이트)
오프셋 10: AFM 1 오프셋 (4바이트)
오프셋 14: AFM 2 오프셋 (4바이트)
...
```

## AFM 리소스 구조

### AFM 헤더 (173바이트)
- 오프셋 165-166: 프레임 수 (WORD, 리틀 엔디언)
- 오프셋 0-164: 애니메이션 메타데이터/설명
- 오프셋 167-172: 예약됨

### 프레임 구조
각 프레임은 8바이트 헤더 + 프레임 데이터로 구성:
```
오프셋 0-1: size (WORD) - 프레임 데이터 크기
오프셋 2-3: param (WORD) - 명령 수
오프셋 4-7: 예약됨
오프셋 8+:  프레임 데이터 (명령 스트림)
```

## 명령 포맷

프레임 데이터는 명령 스트림으로, `param`개의 명령으로 구성됩니다. 각 명령은 명령 바이트로 시작합니다.

### 명령 0x00 - 팔레트 채우기
```
[00][color]
```
단일 색상으로 전체 팔레트(768바이트)를 채웁니다.

### 명령 0x01 - 팔레트 복사
```
[01][palette_data: 768 bytes]
```
768바이트 팔레트 데이터를 직접 복사합니다.

### 명령 0x02 - RLE 팔레트 디코딩
```
[02][rle_data...]
```
팔레트 데이터를 RLE 디코딩합니다.

### 명령 0x04 - 픽셀 버퍼 채우기
```
[04][color]
```
단일 색상으로 전체 픽셀 버퍼(64000바이트)를 채웁니다.

### 명령 0x05 - 픽셀 데이터 복사
```
[05][pixel_data: 64000 bytes]
```
64000바이트 픽셀 데이터를 직접 복사합니다.

### 명령 0x06 - 픽셀 RLE 디코딩
```
[06][rle_data...]
```
픽셀 데이터를 RLE 디코딩합니다.

RLE 포맷:
- `(byte & 0xC0) == 0xC0`인 경우: 카운트 모드
  - count = byte & 0x3F
  - 다음 바이트가 색상값
  - count개의 색상값을 씀
- 그 외: 해당 바이트를 색상값으로 직접 씀

### 명령 0x07 - 점 그리기
```
[07][count:WORD][offset:WORD][color:BYTE]...
```
count개의 점을 그립니다. 각 점은 offset과 color로 구성됩니다.

### 명령 0x08 - 세그먼트 채우기
```
[08][count:WORD][offset:WORD][size:BYTE][color:BYTE]...
```
count개의 세그먼트를 그립니다. 각 세그먼트는 offset부터 시작하여 size개의 color로 채웁니다.

### 명령 0x09 - 데이터 복사
```
[09][count:WORD][dst:WORD][size:BYTE][data: size bytes]...
```
count개의 데이터 블록을 복사합니다. 각 블록은 프레임 데이터에서 픽셀 버퍼의 dst 위치로 복사됩니다.

## 버퍼

### 팔레트 버퍼
- 크기: 768바이트 (256 × 3)
- 포맷: RGB 3바이트 단위, DOS 6비트 (0-63)

### 픽셀 버퍼
- 크기: 64000바이트 (320 × 200)
- 포맷: 팔레트를 가리키는 인덱스 픽셀

## 팔레트 변환

DOS 팔레트는 6비트(0-63)이므로 8비트(0-255)로 변환이 필요합니다:
```
RGB_8bit = min(255, RGB_6bit × 4)
```

## 디코딩 흐름

1. AFM 인덱스를 읽어 모든 AFM 오프셋 확보
2. 각 AFM에 대해:
   - 프레임 수 읽기 (오프셋 165-166)
   - 팔레트 및 픽셀 버퍼 초기화
   - 프레임별 명령 스트림 처리
   - 이미지 프레임 생성
3. GIF 애니메이션 출력
