# FDOTHER.DAT 포맷 문서 v3

## 파일 개요
- 크기: 3,382,481바이트
- 리소스 수: 103개 (4바이트 인덱스, 오프셋 6부터 시작)
- 포맷: 범용 DAT 컨테이너 (sub_111BA로 로드)

## 인덱스 테이블 포맷
역공학된 sub_111BA 기반: `fseek(file, 4 * index + 6, 0)`
- 항목당 4바이트 (uint32, 리틀 엔디언)
- 인접 항목이 (start, end) 쌍을 구성
- start = 현재 항목값, end = 다음 항목값
- 크기 = end - start

### 2. RLE 압축 이미지
역공학된 sub_4E98D의 4모드 RLE 기반:
- 헤더: uint16 width + uint16 height
- 2비트 명령 코드:
  - 00 (0x00-0x3F): 원본 데이터, count=(cmd&0x3F)+1 바이트
  - 01 (0x40-0x7F): 단색 채우기, count=(cmd&0x3F)+1, 1바이트 읽어 반복
  - 10 (0x80-0xBF): 건너뜀/투명, count=(cmd&0x3F)+1 픽셀
  - 11 (0xC0-0xFF): 격자 픽셀 쓰기, count=(cmd&0x3F)+1, 1바이트 읽어 1픽셀 간격으로 씀

### 3. LMI1 애니메이션
역공학된 sub_16886 기반: `*(DWORD*)(data + 4*frame + 6) + data`
- 헤더: "LMI1" (4B) + frame_count (uint16) + first_frame_offset (uint16)
- 오프셋 6부터: 4바이트/프레임의 오프셋 인덱스 테이블
- 각 프레임 = 독립적인 RLE 이미지 (sub_4E98D 포맷과 동일)
