## RLE 디코딩 포맷
함수 `sub_4E98D`에서 RLE 디코딩을 구현합니다:

### 데이터 헤더
```
struct RLEHeader {
    WORD width;      // 너비
    WORD height;     // 높이
    BYTE data[];     // RLE 인코딩 데이터
};
```

### 인코딩 규칙
제어 바이트 상위 비트가 동작 유형을 결정합니다:

| 제어 바이트 범위 | 동작 |
|----------------|------|
| 0x00-0x3F | N+1 픽셀 건너뜀 (투명) |
| 0x40-0x7F | 목적지로 N+1 바이트 복사 |
| 0x80-0xBF | 다음 바이트로 N+1 픽셀 채우기 |
| 0xC0-0xFF | N+1 픽셀 쌍 교번 채우기 |
